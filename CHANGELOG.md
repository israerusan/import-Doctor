# Changelog

## 0.1.1

- Audits Markdown notes one at a time using a reusable file index.
- Adds cancellation, scan-size limits, and actual UTF-8 byte enforcement.
- Keeps exact category totals with a balanced, bounded finding sample.
- Adds Open note and Copy report actions.
- Handles broken links, missing files, ambiguous links, Notion ID suffixes, filename collisions, malformed properties, leftover HTML, and links outside the selected folder.
- Desktop-only, read-only, and local. Detection is heuristic and may miss unsupported patterns.

## 0.1.0

- Initial read-only Notion post-import scanner preview.
